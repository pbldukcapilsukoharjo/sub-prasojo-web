# System Rules: Adminduk Sukoharjo Dashboard

## Core Protocol
- **Framework**: Next.js App Router (TypeScript).
- **Package Manager**: WAJIB gunakan `bun`.
- **Linting**: Gunakan Biome. Jangan gunakan Prettier/ESLint.
- **Architecture**: Gunakan Data Access Layer (DAL) di `src/lib/` atau `src/services/`. Jangan menulis logic API langsung di komponen.

## Language & Tone
- Komentar kode menggunakan Bahasa Indonesia yang profesional.
- Penamaan variabel dan fungsi menggunakan CamelCase dalam Bahasa Inggris.
